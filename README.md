# SPD-to-OR

SPD-to-OR is a simple two-page website about how Sterile Processing supports the operating room and how surgical instruments move through the reprocessing process.

I chose this topic because I have worked as both a surgical technologist and in Sterile Processing. It gave me a topic I already knew while I practiced HTML, CSS, Markdown, GitHub, and project management.
