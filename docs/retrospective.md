# Project Retrospective

**Project Name:** SPD-to-OR  
**Project Manager:** Patrick Casey

## What Went Well?

The biggest thing that went well was choosing a topic I already understood. I did not have to learn the subject before I could start building the website. My experience as a surgical tech and in Sterile Processing helped me decide what information I wanted to include.

I also felt more comfortable with HTML, CSS, Markdown, and GitHub than I did earlier in the course. At the beginning, it took me a while to understand how all of the files and programs connected. By the time I worked on this project, it made a lot more sense.

## What Went Wrong?

The biggest challenge was time. I had to work on the project around work, school, and family, so I could not always finish everything in one sitting.

I also had to pay attention to small things like file names and links. One wrong file name or path can keep part of the website from working, so I had to go back and check those things more than once.

## What Would I Do Differently?

Next time, I would create the full folder structure and get a basic version of the website on GitHub earlier. That would let me find problems with GitHub Pages or links sooner instead of waiting until the project is almost finished.

I would also check my work after each major part instead of doing most of the checking at the end. That would make it easier to catch problems while I still remember what I changed.

This project also showed me how experience from different areas can work together. I used healthcare knowledge I already had while learning technical skills that were newer to me.
